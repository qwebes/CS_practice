## **Короткий огляд кроків вирішення CTF**

1. Отримати **IP-адресу цільової машини** (netdiscover).
2. Просканувати **відкриті порти цільової машини** (**nmap**).
3. Перевірити **HTTP-сервіс** та знайти підказки.
4. Зробити підвищення привілеїв

### Отримання **IP-адресу цільової машини**


```shell
sudo netdiscover -r 192.168.0.0/24
```

###  2. Додаємо домен у `/etc/hosts`

Щоб зручно звертатися до сайту з браузера та утиліт, додамо доменне ім'я:

```
sudo nano /etc/hosts
```

Додаємо новий рядок у кінець файла:


### 3. Скануємо відкриті порти (Nmap)

Запустимо базове сканування, щоб визначити, які сервіси запущені на тачці:

Bash

```
nmap -sC -sV -oA coldbox_scan 192.168.0.154
```

- **`-sC`** — запуск стандартних скриптів Nmap.
    
- **`-sV`** — визначення версій сервісів.
    
- **`-oA`** — збереження результатів сканування у файли.

![[C0lddBox-1785477897921.webp|620]]

### 4. Дослідження вебсервера

Перевіряємо доступні посилання. Результат дає тільки останній:

Ймовірно це імена трьох користувачів.

##### Досліджуємо вордпрес більш детально на наявність додаткової інформації

```
wpscan --url http://192.168.0.154 --enumerate u,p,t
```

Прапорець `--enumerate u,p,t` розшифровується так:

- **`u`** — перераховує юзерів (usernames).
    
- **`p`** — шукає вразливі плагіни (plugins).
    
- **`t`** — шукає теми (themes).

![[C0lddBox-1785478633092.webp|621]]

Знову знаходимо трьох користувачів, вся інша інформація не несе цінності.

##### Проводимо брутфорс за словником. Використовуємо користувача c0ldd

```
wpscan --url http://192.168.0.154/ -U c0ldd -P /usr/share/wordlists/rockyou.txt
```

Якщо такого файлу не знайдено, то спочатку розархіваємо його такою командою:

```
sudo gzip -d /usr/share/wordlists/rockyou.txt.gz
```

### 5. Підвищення привілеїв

Зараз, коли ми знаходимося всередині сервера, давайте пошукаємо файли, які містять важливу інформацію. 
На вебсайті WordPress існує основний файл, що містить базові конфігураційні дані сайту, і він називається **wp-config.php**. 

Ми можемо знайти цей файл у 
```
cd /var/www/html
```

![[C0lddBox-1785480817051.webp]]

Передивляємось зміст файлу **wp-config.php** за допомогою утіліти **cat**:
```
cat wp-config.php
```

![[C0lddBox-1785480909767.webp]]
